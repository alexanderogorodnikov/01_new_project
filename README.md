# VR Snowball Fight

Снежная арена на **Godot 4.4** с поддержкой **OpenXR (VR)** и режима от первого лица для ПК.

## Что уже сделано (этапы 1–2)

### Этап 1 — проект и VR
- Проект Godot 4.4 с включённым OpenXR
- Арена со снегом, стенами-границами и укрытиями-сугробами
- Игрок с автопереключением:
  - **VR**: `XROrigin3D` + `XRCamera3D` + контроллеры рук, стик-передвижение
  - **ПК**: WASD, мышь, прыжок, бег

### Этап 2 — снежки
- Захват снега с поверхности (VR: grip/trigger у земли; ПК: E / ПКМ по снегу)
- Физический снежок (масса, трение, гравитация, разрушение)
- Бросок с импульсом контроллера (VR) или зарядкой ЛКМ (ПК)
- Учебный манекен для проверки попаданий

## Запуск

1. Установите [Godot 4.4+](https://godotengine.org/download)
2. Откройте папку проекта в Godot (`project.godot`)
3. Для VR: SteamVR / OpenXR runtime + шлем
4. Нажмите F5 (Main Scene)

Без шлема игра автоматически стартует в ПК-режиме.

**Meta Quest 2 (через Quest Link / Air Link):** см. пошаговую инструкцию  
[`docs/QUEST2_SETUP.md`](docs/QUEST2_SETUP.md)

## Управление

| Действие | ПК | VR |
|---|---|---|
| Ходьба | WASD | Левый стик |
| Обзор / поворот | Мышь | Голова / правый стик |
| Слепить снежок | E или ПКМ (смотреть на снег) | Grip/Trigger у земли |
| Бросок | ЛКМ (удерживать для силы) | Отпустить Grip/Trigger |
| Курсор | Esc | — |

## Модели

Зимние персонажи собираются из примитивов (`CharacterVisual`): пальто, ноги, варежки, шапка, шарф, лицо.
Арена — мягкие сугробы (`SnowBank`), стены с снежными шапками. Снежки с неровными комками.

## Этап 3 — бот

- Бот патрулирует арену, сближается с игроком, стрейфится
- Уклоняется от летящих снежков (Area3D + боковой рывок)
- Кидает снежки в игрока с простым lead-прицеливанием
- HP игрока и бота на HUD, toast при попадании

## Примечания по VR

- OpenXR включается в `project.godot` (`[xr] openxr/enabled=true`)
- `XRManager` при старте ищет интерфейс OpenXR; при неудаче остаётся ПК-режим
- Для комфорта отключён VSync при активной XR-сессии
